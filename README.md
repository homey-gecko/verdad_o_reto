# 🎲 ¿VERDAD O RETO? ATREVIDO 😈

Un juego de verdad o reto para amigos muy muy muy cercanos o parejas open mind y asi

![licencia]()

---

## CARACTERISTICAS

* **Personalizable:** Puedes añadir jugadores segun genero
* **Variable:** Tiene retos globales, de una persona, de dos personas y de tres personas

## HERRAMIENTAS USADAS

* C++
* CMake
* Raylib

* VSCode

## Requisitos Previos

Antes de compilar, asegúrate de tener instalado en tu sistema:
* Un compilador compatible con **C++17** o superior (GCC, Clang o MSVC).
* **CMake** (versión 3.15 o superior).
* La biblioteca **Raylib** instalada en tu sistema (o configurada mediante submódulos de Git).

## INSTALACION

1. **Clona el repositorio**
2. **Genera la carpeta de compilacion**
3. **Genera los archivos de construccion**
4. **Compila**

``` bash
    git clone https://github.com/homey-gecko/verdad_o_reto
    cd verdad_o_reto

    mkdir build
    cd build

    cmake ..

    cmake --build
```
